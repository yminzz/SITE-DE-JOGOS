
# 🎮 SCourge — Site de Jogos

O SCourge é um projeto acadêmico desenvolvido como parte das atividades da faculdade de Análise e Desenvolvimento de Sistemas.

A proposta do trabalho foi desenvolver um site com temática gamer, utilizando uma identidade visual inspirada no universo dos jogos, com predominância das cores preto e vermelho.

## 🎯 Objetivo do projeto

Criar uma interface voltada ao público gamer, reunindo seções relacionadas a jogos, novidades e comunidades em uma experiência visual organizada.

## 🖥️ Seções do site

- **Início:** apresentação do site.
- **Novidades:** espaço destinado a notícias e atualizações sobre jogos.
- **Navegar:** seção para explorar conteúdos.
- **Comunidades:** área relacionada às comunidades gamer.
- **Conta:** seção destinada à área do usuário.
